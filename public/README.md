# โฟลเดอร์สำหรับใส่รูปภาพตกแต่งสาธารณะ (Public Assets)

คุณสามารถนำไฟล์ภาพ (PNG, JPG, SVG, WebP) มาอัปโหลดไว้ในโฟลเดอร์นี้ได้โดยตรงผ่าน File Explorer ทางด้านซ้ายของหน้าจอ:

### โครงสร้างที่แนะนำ:
- `/public/decorations/` : สำหรับรูปภาพตกแต่ง ลายไทย ช่อดอกไม้ พุ่มผ้าป่า หรือตราสัญลักษณ์
- `/public/frames/` : สำหรับไฟล์กรอบรูปโปรไฟล์แบบโปร่งใส (Transparent PNG)
- `/public/images/` : สำหรับรูปภาพทั่วไป

ไฟล์ที่อยู่ในโฟลเดอร์ `/public/` สามารถเรียกใช้งานในเว็บได้โดยตรงผ่าน Path เช่น:
- `/decorations/my-image.png`
- `/frames/frame-official.png`
